# Data Dictionary - TerraModel

All files in `data/raw/`, `data/processed/`, and `data/threat/` are generated by scripts in `collectors/` and `pipeline/`. The folder structure is version-controlled; the data files themselves are gitignored and reproduced from code.

## `data/raw/`

### `plc_telemetry.parquet`
PLC register samples at 10 Hz across 4 PLCs over 8 scenarios.

| Column | Type | Description |
|---|---|---|
| plc_id | int | PLC identifier (0-3) |
| register | str | Register name (`conveyor_speed` in the baseline) |
| value | float | Observed register value |
| setpoint | float | Commanded setpoint for the register |
| scenario_id | int | Scenario index (0 to 7) |
| attack_class | str | `normal` or one of 7 ATT&CK IDs |
| is_attack | int | 1 if the scenario is an attack scenario |
| timestamp | float | Seconds from scenario start |

### `robot_states.parquet`
Robot joint-state samples at 20 Hz for 3 robots x 6 joints.

| Column | Type | Description |
|---|---|---|
| robot_id | int | Robot identifier (0-2) |
| joint | int | Joint index (0-5) |
| commanded | float | Commanded position (radians) |
| actual | float | Actual position (radians) |
| torque | float | Joint torque |
| cmd_source | str | `operator_a`, `operator_b`, `scheduler`, or an anomalous source |
| cmd_interval_ms | float | Interval between commands |
| scenario_id | int | Scenario index |
| attack_class | str | `normal` or one of 7 ATT&CK IDs |
| is_attack | int | 1 if the scenario is an attack scenario |
| timestamp | float | Seconds from scenario start |

### `network_flows.parquet`
Per-second network flow summaries.

| Column | Type | Description |
|---|---|---|
| pkt_count | int | Packet count per second |
| pkt_size_mean | float | Mean packet size (bytes) |
| pkt_size_std | float | Packet size standard deviation |
| inter_arrival_mean_ms | float | Mean inter-arrival time (ms) |
| unique_src_ips | int | Unique source IPs |
| unique_dst_ips | int | Unique destination IPs |
| frac_modbus_tcp | float | Fraction of packets Modbus TCP |
| frac_ethernet_ip | float | Fraction EtherNet/IP |
| frac_profinet | float | Fraction PROFINET |
| frac_http | float | Fraction HTTP |
| frac_other | float | Fraction other |
| scenario_id, attack_class, is_attack, timestamp | | As above |

## `data/processed/`

Clean versions of the three raw files (`*_clean.parquet`), per-agent feature frames (`agent1_features.parquet`, `agent2_features.csv`, `agent3_features.parquet`), and train/val/test splits for Agents 1 and 3.

The `cleaning_report.json` records per-stream removal counts and reasons. The `split_report.json` records class balance per split.

## `data/threat/`

### `attack/ics-attack.json`
Full MITRE ATT&CK for ICS STIX bundle. Downloaded live from the MITRE GitHub repo. CC BY 4.0.

### `attack/techniques_lookup.json`
Flat lookup of the 7 techniques TerraModel targets:
```json
{
  "T0836": {"name": "Modify Parameter", "description": "...", "url": "https://attack.mitre.org/techniques/T0836/", "tactics": [...]},
  ...
}
```

### `cisa/advisories.json` and `cisa/advisories_flat.csv`
CISA ICS advisories. Live-fetched when the network allows. Falls back to a 25-advisory sample bundled in `collectors/fetch_cisa.py`. The flat CSV adds derived columns: `asset_type`, `age_days`, `exposure_hint`.
